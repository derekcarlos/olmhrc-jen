# Fonts for generated sharing images

These unmodified fonts are bundled so Sharp can render the site's Figtree and Gentium Book Plus typography without network access during local or GitHub builds. They are build inputs, not additional visitor font downloads. Run generation from the project root.

Downloaded from the official Google Fonts repository on November 3, 2026:

- [Figtree](https://github.com/google/fonts/tree/main/ofl/figtree): `Figtree[wght].ttf`, stored as `Figtree.ttf`; Git blob SHA-1 `579e2ab5f30beb21cd0b618dd0796b0fce0eff8e`.
- [Gentium Book Plus](https://github.com/google/fonts/tree/main/ofl/gentiumbookplus): `GentiumBookPlus-Regular.ttf`; Git blob SHA-1 `c45ac365da2392996856afc6c8475734f6cd4042`.

Both use the SIL Open Font License; the complete license and copyright notices are included in `Figtree-OFL.txt` and `GentiumBookPlus-OFL.txt`. Preserve them when updating these files.
